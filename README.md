# Strong Number in Java

A simple Java program to check whether a given number is a Strong number.

## What is a Strong Number?

A Strong number is a number in which the sum of the factorials of its digits is equal to the original number.

### Example

For `145`:

`1! + 4! + 5! = 1 + 24 + 120 = 145`

Therefore, `145` is a Strong number.

## Sample Output

```text
Enter a number: 145
145 is a Strong number.
```
